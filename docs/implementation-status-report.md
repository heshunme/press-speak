# Press Speak 当前实现情况报告

- 报告日期：2026-07-27
- 设计依据：[`design.md`](design.md)
- 设计版本标识：`design.md` 当前内容快照，SHA256 `55c6622770af3b447679b679ad3f910c80e6446e29c94a903b14dfba70e5e817`
- 说明：该 `design.md` 未内置独立版本号，本报告按当前文件内容出具。

## 结论

当前仓库已经实现了设计稿里的 MVP 主链路，覆盖托盘常驻、全局 PTT 热键、录音、模型下载与校验、本地识别、文本写回、剪贴板回退、设置页、流式预览、标点后处理、通用后处理规则、本地日志、登录后自动启动、管理员模式启动和单实例协调。

当前实现会在最终写回前依次执行“离线标点”和“通用后处理规则”两个可开关增强层；流式结果仅用于录音期间的预览，不会持续改写目标输入框。

## 已实现内容

- 托盘常驻入口已接入，启动后不弹主界面，托盘菜单可打开设置、触发模型下载/重载、切换听写和退出。
- 全局热键已实现按下开始、释放结束的 PTT 语义，默认仍是 `Alt + Oem3`。
- 音频录制已实现，输入格式固定为 `16 kHz / mono / 16-bit PCM`；单次录音上限默认 5 分钟，可在设置页调整，达到上限后会自动结束并继续写回已录内容。
- 热键释放后的尾录延迟默认 1 秒，可在设置页调整，最大 5 秒。
- 录音结束后会先做首尾静音裁剪，再送入 `sherpa-onnx` FunASR Nano int8 识别引擎。
- 模型可按需自动下载、解压和校验，覆盖离线、流式和标点三类模型，模型目录默认落在本地用户目录。
- 文本回写已实现 `SendInput(KEYEVENTF_UNICODE)` 优先，失败后走剪贴板粘贴回退。
- 识别前会捕获前台窗口上下文，并在密码输入框场景拒绝注入。
- 设置页已支持热键、输入设备、模型目录、识别模式、单次录音上限、松键尾录延迟、流式预览、剪贴板回退、自动下载、标点、后处理规则、识别热词和登录后自动启动等配置。
- 识别热词已实现：设置页可维护热词表（上限 100 个，保存时统一清洗为每行一个词），经 `OfflineFunAsrNanoModelConfig.Hotwords` 注入 FunASR-Nano 的 LLM prompt 做软偏置；仅作用于离线最终结果，流式预览不受影响。热词变化会按“模型目录 + 热词”组合指纹在下次识别前重建离线识别器，无需重启应用。
- 设置页已扩展为页签结构，支持后处理规则列表、编辑、顺序调整、测试、保存和单条内置规则恢复默认。
- 标点处理失败时会回退原始文本，不影响主流程。
- 后处理规则系统已接入最终写回前链路，内置 `trim-whitespace`、`normalize-fullwidth-space`、`collapse-multiple-spaces` 和 `english-acronym-join` 四条默认规则。
- 用户可通过独立规则文件覆盖内置规则或新增自定义 `exact_replace` / `regex_replace` 规则。
- 本地日志已实现，日志文件按日期落盘。
- 支持通过 `--admin` 或托盘入口请求管理员模式，并在 UAC 取消时继续保留普通实例；提升子进程会核对发起账号 SID，改用另一管理员账号时拒绝启动。
- 登录后自动启动支持普通和管理员两种模式：普通模式使用当前用户启动项；管理员模式在普通权限下通过 UAC 维护最高权限登录任务，后续登录启动不再弹出 UAC。
- 自动启动注册以当前可执行文件路径为准；普通启动项与管理员任务切换时先建立并校验新配置，再移除旧配置，取消 UAC 或创建失败不会破坏原启动方式。
- 创建管理员登录任务前会使用当前账号的 UAC 非提升令牌检查有效权限，并逐项检查完整发布目录及路径组件的 owner/DACL 和盘符设备映射；除 SYSTEM、Administrators、TrustedInstaller 外的主体只要可写，或遇到异账号凭据、非固定磁盘、网络/SUBST 路径、重解析点及无法可靠判定的环境，都会被拒绝。
- 当校验失败仅因安装目录自身 owner/DACL 允许当前用户写入时（例如自建在非 C 盘的发布目录），托盘“以管理员身份重启”和设置页管理员自启都会先弹窗询问是否自动修复；确认后单独提权 `icacls.exe` 加固目录，再重新走未放宽的原校验判定，修复范围不含上级目录。
- 旧路径、重复、禁用或任务 ACL 无法确认的注册会作为“管理员模式待修复”显示，用户可保存以重建，或切换模式/关闭以移除；只有查询本身失败时才禁用自启控件，其他设置仍可保存。
- 已按当前用户和 Windows 会话实现单实例协调；普通模式与管理员模式切换时不会长期留下两个工作实例，异账号 UAC 也不会进入另一个单实例域。
- 托盘提示和设置页会显示当前是普通模式还是管理员模式。

## 关键实现选择

- 热键采用 `WH_KEYBOARD_LL` 低级键盘钩子，而不是 `RegisterHotKey`，以满足“按下开始、释放结束”的 PTT 语义。
- 音频采集采用 `WaveInEvent`，采样格式固定为 `16 kHz / mono / 16-bit PCM`，并通过简单裁剪满足首版录音链路。
- 标点后处理作为独立增强层存在，只作用于最终写回文本。
- 热词采用 sherpa-onnx 原生的 FunASR-Nano prompt 注入（“热词列表：[…]”拼入 user prompt），是概率性软偏置而非硬替换；确定性的错误映射仍建议用后处理规则兜底。离线引擎同时显式设置 `Itn = 1`（C# 绑定默认 0 与上游 Python 默认不一致，且 0 会在 prompt 追加“不进行文本规整”）。
- 因 sherpa-onnx C# 绑定的 config 字符串按 ANSI（`LPStr`）marshal，`app.manifest` 已固定进程 ANSI 代码页为 UTF-8，避免中文热词与绑定自带中文 prompt 在 GBK 代码页系统被转码破坏。
- 通用后处理规则也只作用于最终写回文本，不影响流式预览或录音期间的预览状态。
- `normalize-fullwidth-space` 和 `collapse-multiple-spaces` 以“内置配置规则”形式落地，而不是单独规则类，行为与设计文档目标等价。
- 管理员自动启动采用当前用户的登录触发计划任务，并使用最高可用权限、交互令牌、忽略重复实例和无限执行时长；任务维护使用显式提升的短生命周期子进程。
- 计划任务 XML 通过 Windows Task Scheduler COM 直接从内存注册，不经过普通用户可替换的临时文件。
- 管理员任务与提升入口通过受保护的命令包装启动；包装固定系统命令解释器路径，清理 .NET 运行时、启动钩子、GC/profiler 和诊断注入变量，再启动应用。
- 任务安全描述符使用受保护 DACL，仅允许 SYSTEM/Administrators 完全控制和目标用户只读；查询时会同时校验任务 XML 与 DACL。
- 安装目录 ACL 修复的提权对象固定是 Windows 自带的 `icacls.exe`/`cmd.exe`，绝不是应用自身的 exe 或安装目录里的 `.cmd` 包装文件，避免在目录仍可被普通用户写入时就提权执行了可能已被篡改的内容；修复结果不作为提权依据，之后仍会重新调用未改动的校验方法判定。
- 设置保存先完成可能触发 UAC 的自启变更，再分别原子替换规则和主设置文件；后续失败时会尽力恢复原配置内容与原模式，但跨资源补偿可能部分失败，恢复管理员任务时也可能再次请求 UAC。

## 尚未覆盖或未做完整验证

- 实时流式上屏未实现，当前只提供录音期间的流式预览，不会把流式结果直接持续写回目标输入框。
- 真正的 ITN 文本规整未实现（后续计划）。当前 `Itn = 1` 在本项目配置下实际不做任何规整：sherpa-onnx v1.12.34 的 `ApplyInverseTextNormalization` 只在配置了 `OfflineRecognizerConfig.RuleFsts`/`RuleFars`（kaldifst 规则 FST 文件）时才执行转换，项目未配置，因此该标志的唯一实际效果是去掉 prompt 里“不进行文本规整”后缀，数字风格由 LLM 自行决定、输出混杂（同一段话可能既出“三点五”又出“375 . 1236”，后者小数点两侧空格是 LLM tokenizer 解码痕迹）。2026-07-27 真机确认现状可接受，留作以后收敛，候选路径：
  1. 分发 sherpa-onnx 官方中文数字 ITN FST（如 `itn_zh_number.fst`）并设置 `RuleFsts`，需纳入模型下载/校验流程；
  2. 先用后处理规则引擎加低成本规则，如数字间 `" . "` → `"."`（regex `(?<=\d)\s*\.\s*(?=\d)`）；
  3. 若新数字风格反馈不佳，把 `SherpaFunAsrNanoEngine` 里的 `Itn` 改回 0 即恢复旧 prompt 行为。
- ITN 显式开关未实现（当前硬编码开启，未在设置页暴露）。
- 云同步未实现。
- 登录后自动启动的真实注销/登录行为，以及管理员模式配置与移除时的 UAC 流程，仍需在 Windows 环境执行回归清单。
